# kind decision — choosing between options

Chapters: **the question → option A → option B → the criterion → the choice.**

- **The question:** the decision as a question someone would ask out loud («who looks after the database at 3 a.m.?»).
- **Option A / Option B:** the same layout for both, side by side (left and right), each with its prop and its one
  number (cost, time) — `text … below <id>`.
- **The criterion:** what decides it, as a value the person can move (`param` with a `counter`) or a `switch` —
  so they see the answer change.
- **The choice:** which option wins, and why, in a `highlight` in the last chapter. **With no highlight and no value
  the build says «the decision does not say which option wins, nor why».**

Common mistakes: more than three options (split the decision); a criterion that is not in the drawing; hiding the
cost of the winner.
