How it works

  1. Claude chooses the everyday thing to tie the idea to, who it is for and which number moves, and draws at once — then says what it chose and offers to change it. For a class it asks first.
  2. It writes a short text recipe — what to draw, step by step — never the drawing itself.
  3. scripts/build.mjs checks the recipe, builds one HTML file and, with a headless browser, checks that nothing leaves the paper and no text covers another.
